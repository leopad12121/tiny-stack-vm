# tiny-stack-vm

A tiny stack virtual machine for make.fun's "Build a tiny stack virtual machine" bounty: 32-bit wrapping integers, a 256-value data stack, a 64-deep call stack, 256 words of memory, `IN`/`PRINT`/`PUTC` I/O, and all ten traps from ISA v1, with the 1,000,000-step and 65,536-byte output limits.

Run: `MAKEFUN_INPUT_DIR=<input> MAKEFUN_OUTPUT_DIR=<output> node main.ts`
